# 💰 SmartSpend

### Personal Finance Assistant for Smarter Expense Management

SmartSpend is a simple and intelligent personal finance assistant that helps users track daily expenses, organize transactions, monitor budgets, and understand their spending patterns through clear financial insights.

## 🚀 Features

- 💰 Expense tracking
- 🎯 Monthly budget monitoring
- 📊 Spending dashboard
- 🏷️ Automatic expense categorization
- 📈 Spending trend visualization
- 🥧 Category-wise spending analysis
- 📁 CSV transaction import
- 🔎 Transaction search and filtering
- 💡 Smart spending insights
- ⬇️ Downloadable transaction data

## 🧠 Smart Categorization

SmartSpend automatically suggests an expense category based on the transaction description.

Supported categories include:

- Food
- Transport
- Shopping
- Entertainment
- Education
- Bills
- Health
- Other

## 📊 Dashboard

The dashboard provides:

- Total spending
- Number of transactions
- Remaining budget
- Average transaction amount
- Budget progress
- Category-wise spending
- Spending trends
- Personalized spending observations

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
